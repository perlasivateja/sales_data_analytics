# 📊 Sales Data Analytics Dashboard

## 📌 Project Overview

This project performs end-to-end sales data analysis using Python. The project focuses on data cleaning, exploratory data analysis, business insights, and data visualization using the Superstore dataset.

The analysis helps understand sales performance, profitability, customer segments, regional performance, product performance, and sales trends.

---

## 🎯 Objectives

- Clean and preprocess sales data
- Perform exploratory data analysis
- Analyze sales and profit performance
- Identify top-performing products
- Analyze customer segments and regions
- Study sales trends over time
- Generate business insights using visualizations

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook
